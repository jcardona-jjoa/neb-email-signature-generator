# sig-assets

Copies of the images used by the signature generator, kept in the same
folder as `index.html`.

These exist only so the **Save as PNG / JPG** buttons work. A browser will
not let a page save a picture built from images on another domain, so the
export needs same-folder copies.

The signature itself does **not** use these files. It points at
`www.jackandjillinc.org`, which is what recipients load, and that should
stay on a domain the organisation controls.

Filenames must match the last part of the URLs in `index.html`.
